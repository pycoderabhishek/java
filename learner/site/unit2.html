Detailed Theory (Exam-Oriented)

Unit II builds logical foundations in Java. Operators perform arithmetic, relational, logical, and assignment operations. Typecasting converts one data type to another and can be implicit (widening) or explicit (narrowing). Control statements (`if`, `switch`) and loops (`for`, `while`, `do-while`) define program flow, while `break` and `continue` control loop execution.

Arrays store homogeneous data and are indexed from 0. Object-oriented programming concepts are introduced through classes and objects. Constructors initialize objects and can be default or parameterized. Method overloading supports multiple methods with the same name but different parameters, while access specifiers (`public`, `private`, `protected`, default) define visibility.

Definitions & Explanations

Typecasting
Conversion of one data type to another (widening or narrowing).
Loop
A control structure that repeats a block of code based on a condition.
Constructor
A special method used to initialize objects.
Method Overloading
Multiple methods with the same name but different parameter lists.
Access Specifier
Keyword that sets visibility: `public`, `private`, `protected`, or default.

Code Examples

Simple: Control Flow

class ControlDemo {
  public static void main(String[] args) {
    int n = 5;
    if (n % 2 == 0) {
      System.out.println("Even");
    } else {
      System.out.println("Odd");
    }

    for (int i = 1; i <= 3; i++) {
      System.out.println("i = " + i);
    }
  }
}

Advanced: Constructor + Method Overloading

class Box {
  int l, b, h;

  Box() {              // default constructor
    l = b = h = 1;
  }

  Box(int l, int b, int h) {  // parameterized
    this.l = l; this.b = b; this.h = h;
  }

  int volume() { return l * b * h; }
  int volume(int scale) { return l * b * h * scale; } // overloading
}

class Demo {
  public static void main(String[] args) {
    Box a = new Box();
    Box b = new Box(2, 3, 4);
    System.out.println(a.volume());
    System.out.println(b.volume(2));
  }
}

Key Points for Revision

  • Use explicit casting when narrowing types.
  • `switch` is best for discrete choices; `if` is for complex conditions.
  • Arrays are fixed-size and zero-indexed.
  • Constructors initialize objects and share the class name.
  • Overloading is compile-time polymorphism.

Practical Section

Program: Count Even/Odd in Array

class CountEvenOdd {
  public static void main(String[] args) {
    int[] arr = {2, 5, 8, 9, 12};
    int even = 0, odd = 0;
    for (int n : arr) {
      if (n % 2 == 0) even++; else odd++;
    }
    System.out.println("Even: " + even);
    System.out.println("Odd: " + odd);
  }
}
Output: Even: 3 Odd: 2

Step-by-step Explanation

  1. Create an integer array.
  2. Loop through each element using `for-each`.
  3. Check parity with `% 2` and update counters.
  4. Print the totals.

Question Bank

5 Marks Questions

  1. Explain implicit and explicit typecasting with examples.
    Implicit (widening) happens automatically, e.g., `int` to `double`. Explicit (narrowing) requires a cast, e.g., `double d=9.8; int x=(int)d;`.
  2. Write the syntax of `for` and `switch` statements.
    `for(init; condition; update){...}` and `switch(expr){case x:...break; default:...}`.

8–10 Marks Questions

  1. Discuss constructors and their types with a suitable example.
    Constructors initialize objects. Types: default (no args) and parameterized. Example: `Box(){...}` and `Box(int l,int b,int h){...}` for different initial values.
  2. Explain method overloading and access specifiers in Java.
    Overloading allows same method name with different parameters (compile-time). Access specifiers define visibility: `public`, `private`, `protected`, and default.

15 Marks Long Question

Describe control statements and looping structures in Java with examples and use cases.
Control statements include `if-else` for conditional branching and `switch` for multi-way selection. Looping constructs include `for` (known iterations), `while` (pre-test), and `do-while` (post-test). `break` exits a loop/switch, while `continue` skips to the next iteration. Use `if` for complex conditions, `switch` for discrete values, `for` when iterations are known, and `while/do-while` for condition-based repetition.
