Detailed Theory (Exam-Oriented)

Applets are small Java programs that run inside a browser or applet viewer. They follow a lifecycle: `init()` for initialization, `start()` when execution begins, `paint()` for rendering, `stop()` when paused, and `destroy()` for cleanup. Applet tags in HTML specify the class and dimensions for execution.

The Abstract Window Toolkit (AWT) provides GUI components such as `Button`, `Label`, `TextField`, and containers like `Frame` and `Panel`. Layout managers (`FlowLayout`, `BorderLayout`, `GridLayout`) control component positioning. Servlets handle HTTP requests on the server side, while RMI allows method calls across JVMs for distributed applications.

Definitions & Explanations

Applet
A Java program embedded in a web page and executed by a browser or applet viewer.
AWT
Java's GUI toolkit for creating windows, buttons, and other components.
Layout Manager
Strategy object that arranges components in a container.
Servlet
Server-side Java program that handles HTTP requests and responses.
RMI
Remote Method Invocation allows Java objects to communicate across JVMs.

Code Examples

Simple: Applet Skeleton

import java.applet.Applet;
import java.awt.Graphics;

public class HelloApplet extends Applet {
  public void init() {
    // initialization
  }

  public void paint(Graphics g) {
    g.drawString("Hello Applet", 20, 20);
  }
}
// <applet code="HelloApplet" width="200" height="100"></applet>

Advanced: AWT Frame with Button

import java.awt.*;
import java.awt.event.*;

class MyFrame extends Frame implements ActionListener {
  Button btn = new Button("Click");

  MyFrame() {
    setLayout(new FlowLayout());
    add(btn);
    btn.addActionListener(this);
    setSize(300, 200);
    setVisible(true);
  }

  public void actionPerformed(ActionEvent e) {
    System.out.println("Button clicked");
  }
}

public class Demo {
  public static void main(String[] args) {
    new MyFrame();
  }
}

Key Points for Revision

  • Applet lifecycle: `init()` → `start()` → `paint()` → `stop()` → `destroy()`.
  • AWT provides GUI components and containers.
  • Layout managers control component placement.
  • Servlets run on server side for web apps.
  • RMI enables distributed Java communication.

Practical Section

Program: AWT Button Click

import java.awt.*;
import java.awt.event.*;

class ClickDemo extends Frame implements ActionListener {
  Button btn = new Button("Click Me");

  ClickDemo() {
    setLayout(new FlowLayout());
    add(btn);
    btn.addActionListener(this);
    setSize(250, 150);
    setVisible(true);
  }

  public void actionPerformed(ActionEvent e) {
    System.out.println("Button clicked!");
  }

  public static void main(String[] args) {
    new ClickDemo();
  }
}
Output: Button clicked!

Step-by-step Explanation

  1. Create a `Frame` and add a `Button`.
  2. Attach an `ActionListener` to handle clicks.
  3. Print a message in `actionPerformed()`.

Question Bank

5 Marks Questions

  1. List the applet lifecycle methods in order.
    `init()` → `start()` → `paint()` → `stop()` → `destroy()`.
  2. What is an AWT layout manager? Give two examples.
    A layout manager arranges components in a container. Examples: `FlowLayout`, `BorderLayout`, `GridLayout`.

8–10 Marks Questions

  1. Explain AWT component hierarchy with a neat diagram.
    AWT has `Component` at the top, then `Container` and subclasses like `Window` → `Frame`, and UI controls like `Button`, `Label`, `TextField`. Containers hold components and use layouts for placement.
  2. Describe applet tags and their purpose with an example.
    Applet tags embed applets in HTML: `<applet code="MyApplet" width="300" height="200">...</applet>`. Attributes define class and dimensions.

15 Marks Long Question

Write an essay on servlets and their role in web applications. Include request/response flow.
Servlets are server-side Java components that handle HTTP requests. A client sends a request to the web server, which forwards it to the servlet container. The servlet processes input using `doGet()`/`doPost()`, interacts with business logic or databases, and returns a response. Servlets are platform-independent, reusable, and scalable. They form the core of many Java web applications by separating presentation and logic.
