Detailed Theory (Exam-Oriented)

Inheritance allows a new class (subclass) to acquire properties and behavior of an existing class (superclass), enabling code reuse and hierarchical design. The `this` keyword refers to the current object, while `super` accesses superclass members. Method overriding enables runtime polymorphism when a subclass provides a specific implementation for a superclass method.

Abstract classes provide partial implementation and cannot be instantiated, whereas interfaces define a contract of methods a class must implement. Packages group related classes and help avoid naming conflicts. String handling is crucial in Java: `String` is immutable, `StringBuffer` is mutable and thread-safe. Exception handling uses `try`, `catch`, `finally`, and `throw` to manage runtime errors, while multithreading improves performance by executing tasks concurrently.

Definitions & Explanations

Inheritance
Mechanism where a subclass inherits properties and methods from a superclass.
Interface
A collection of abstract methods that define a contract for implementing classes.
Abstract Class
A class that cannot be instantiated and may contain abstract methods.
Exception
An event that disrupts normal program flow and can be handled using `try`/`catch`.
Thread
A lightweight subprocess for concurrent execution within a program.

Code Examples

Simple: Interface Implementation

interface Printer {
  void print();
}

class LaserPrinter implements Printer {
  public void print() {
    System.out.println("Printing...");
  }
}

class Demo {
  public static void main(String[] args) {
    Printer p = new LaserPrinter();
    p.print();
  }
}

Advanced: Custom Exception + Thread

class InvalidAgeException extends Exception {
  InvalidAgeException(String msg) { super(msg); }
}

class Worker extends Thread {
  public void run() {
    System.out.println("Thread running");
  }
}

class Test {
  static void checkAge(int age) throws InvalidAgeException {
    if (age < 18) throw new InvalidAgeException("Too young");
  }

  public static void main(String[] args) throws Exception {
    checkAge(20);
    new Worker().start();
  }
}

Key Points for Revision

  • Overriding is runtime polymorphism; overloading is compile-time.
  • Use `super` to access parent class members.
  • `String` is immutable; `StringBuffer` is mutable and thread-safe.
  • Interfaces define contracts; classes implement them.
  • Threads run concurrently and improve responsiveness.

Practical Section

Program: Method Overriding

class Animal {
  void sound() { System.out.println("Animal sound"); }
}

class Dog extends Animal {
  void sound() { System.out.println("Bark"); }
}

class Test {
  public static void main(String[] args) {
    Animal a = new Dog();
    a.sound();
  }
}
Output: Bark

Step-by-step Explanation

  1. Create a superclass `Animal` with method `sound()`.
  2. Override `sound()` in subclass `Dog`.
  3. Call method using a parent reference to show runtime polymorphism.

Question Bank

5 Marks Questions

  1. Define inheritance and state its advantages.
    Inheritance is the mechanism where a subclass acquires properties of a superclass. Advantages: code reuse, hierarchical design, and easy maintenance.
  2. Differentiate between abstract class and interface.
    Abstract classes can have concrete methods and fields; interfaces define method contracts. A class extends one abstract class but can implement multiple interfaces.

8–10 Marks Questions

  1. Explain method overriding with suitable example and rules.
    Overriding occurs when a subclass provides a specific implementation of a superclass method with same signature. Rules: same name, parameters, return type (covariant allowed), and cannot reduce access level.
  2. Describe string handling in Java (String vs StringBuffer).
    `String` is immutable; operations create new objects. `StringBuffer` is mutable and thread-safe, suitable for frequent modifications.

15 Marks Long Question

Discuss exception handling and multithreading in Java with example scenarios.
Exception handling uses `try`, `catch`, `finally`, `throw`, and `throws` to manage runtime errors and maintain normal flow. Checked exceptions must be handled or declared. Multithreading uses the `Thread` class or `Runnable` interface to run tasks concurrently, improving responsiveness and CPU utilization. Synchronization avoids race conditions. Examples include handling file I/O errors and running UI updates while background tasks execute.
